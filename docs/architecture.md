# Architecture

llmtap is a small, dependency-free HTTP reverse proxy. It's built on `http.server.ThreadingHTTPServer`, `http.client`,
`ssl`, `sqlite3` and `json`, all from the Python 3.11+ standard library.

## Request pipeline

```
client ──HTTP──▶ ThreadingHTTPServer ──▶ LLMTap.handle(method, path, headers, body, respond)
                                             │
             path starts with /_llmtap/ ─────┼──▶ dashboard.handle_internal()  (UI + JSON API + SSE)
             GET / (no route) ───────────────┼──▶ 302 → /_llmtap/
                                             ▼
   1. providers.resolve_route()     which upstream? (/<name>/ prefix, /v1/messages, anthropic headers, else openai)
   2. providers.parse_json()        model, stream flag
   3. providers.tags_from_headers() X-LLMTap-Session / X-LLMTap-Tag-*  (stripped before forwarding)
   4. guard.apply_guard()           off | warn | redact | block ──▶ 400 provider-shaped error, source="blocked"
   5. cache.cache_key()             sha256(provider, path, canonical JSON body)
   6. budget.check()                daily / session cap, loop detector ──▶ 429, source="budget" | "loop"
   7. cassette.lookup()             recorded? ──▶ replay verbatim, source="cassette"
      cache.get()                   cached?   ──▶ replay verbatim, source="cache"   (saved_usd = original cost)
      (replay mode miss)            ──▶ 409 unless allow_miss
   8. forward upstream              http.client, HTTPS via ssl.create_default_context(), timeout
                                    text/event-stream: relay each chunk immediately (chunked), record TTFT
                                    connection error ──▶ 502, source="error"
   9. usage + cost                  providers.parse_sse / extract_usage (fallback: estimate_usage), pricing.cost_usd
  10. side effects                  budget.add_spend, cache.put / cassette.record (2xx only),
                                    store.record, bus.publish, term.log_exchange
```

Every response gets `x-llmtap-id` and `x-llmtap-source` headers. Errors generated by llmtap itself (400/409/429/502)
use the provider's own error JSON shape, so SDKs raise their normal exception types with a readable message.

## Design decisions

**Base URL, not MITM.** llmtap is a reverse proxy addressed by base URL, not an `HTTP_PROXY` that intercepts TLS. No
certificates to install, nothing to trust, and it works with every SDK that lets you set a base URL.

**Standard library only.** `pip install llmtap` pulls in nothing else, so it can't conflict with your app's
dependencies and it installs in seconds in CI. The trade-off is that we write our own SSE parsing and use
`http.client` directly.

**Streaming is relayed, not buffered.** For `text/event-stream` responses each upstream chunk is written to the client
straight away using chunked transfer encoding, while a copy is accumulated for usage parsing and recording. Time to first
token is recorded as `ttft_ms`.

**Usage comes from the provider when possible.** Token counts are read from the response JSON or the SSE events
(`message_start` / `message_delta` for Anthropic, the final usage chunk for OpenAI chat, `response.completed` for the
Responses API). When the provider doesn't report usage, llmtap estimates it at about 4 characters per token and marks the
exchange `usage.estimated = true`.

**One key for cache, cassettes and loops.** `cache_key()` hashes provider, path (no query) and canonical JSON with
volatile top-level fields (`user`, `metadata`, `request_id`) removed. The same identity powers cache hits, cassette
matching and loop detection.

**Thread safety.** The server handles each connection in its own thread. `Store`, `ResponseCache`, `Cassette` and
`Budget` each guard their state with a lock. SQLite connections are opened with `check_same_thread=False`.

**Provider-shaped errors.** When llmtap refuses a request it answers in the provider's error format
(`{"type":"error","error":{…}}` for Anthropic, `{"error":{…}}` for OpenAI), so applications fail the same way they would
on a real API error.

## Data model

`Exchange` is the unit of everything: one request/response through the proxy. Its fields cover identity (`id`, `ts`),
routing (`provider`, `style`, `path`, `model`), bodies (`request_body` as sent upstream, `response_body` raw JSON or raw
SSE), timing (`latency_ms`, `ttft_ms`), `usage`, `cost_usd`, `saved_usd`, `source`, `tags`, `guard_findings`, `error`,
and `output_text` (assistant text, for search and previews).

`source` is one of `upstream`, `cache`, `cassette`, `blocked`, `budget`, `loop` or `error`.

## Testing

Tests never touch the network. They start `MockUpstream` on `127.0.0.1:0`, point `cfg.upstreams` at it, and run
`LLMTap` with `port=0` and `db_path=":memory:"`. The mock implements Anthropic Messages, OpenAI Chat Completions,
Responses, Embeddings and Models, streaming and non-streaming, and accepts magic words (`MOCK_ERROR_500`,
`MOCK_ERROR_429`, `MOCK_SLOW`) to simulate failures.
